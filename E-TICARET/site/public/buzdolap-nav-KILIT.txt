KİLİT — Soğutma menüsü · Buzdolapları (alt dal yok, tek arama filtresi)
Onay: 2026-05-30 · Commit referans: a2ffd88
═══════════════════════════════════════════════════════════════════════════

Bu dosya, Buzdolapları menü satırının yanlış tip filtrelemesi yapan
alt flyout ile geri gelmemesi içindir.
Değiştirmeden önce kullanıcıdan AÇIK ONAY alın.

── Beklenen davranış ─────────────────────────────────────────────────────
  Soğutma → Buzdolapları: TEK satır, sağ flyout / alt dal YOK.
  Tıklanınca: searchFilter("buzdolab|buzdolap") — tüm buzdolabı ürünleri.

── Kilitli nav.js satırı ─────────────────────────────────────────────────
  { label: "Buzdolapları", labelKey: "nav.sub.buzdolaplari", search: "buzdolab|buzdolap" }

YASAK (onay olmadan):
  • Buzdolapları altına Tezgah Tipi / Make Up / Cihazaltı / Dik Tip / Pastane subs
  • Buzdolapları için ?tip=tezgah-tipi-buzdolabi vb. flyout yönlendirmesi
  • Alt dalı geri getiren nav generator veya merge

── Kilitli dosyalar ───────────────────────────────────────────────────────
  public/nav.js                    — sogutma.subs Buzdolapları düz satır
  lib/shop/assets.ts               — SHOP_ASSET_V (nav cache bust)

── Not ───────────────────────────────────────────────────────────────────
  eq-dept-tips.js içindeki tezgah-tipi / dik-tip tip kayıtları kalabilir
  (eski GEO URL yönlendirmesi); menüde alt dal olarak gösterilmez.

── Deploy / doğrulama ─────────────────────────────────────────────────────
  npm run verify:buzdolap-nav-kilit
  Canlı: /shop/sogutma → Buzdolapları tık → flyout açılmaz, filtre uygulanır
