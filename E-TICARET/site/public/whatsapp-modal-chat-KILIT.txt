Modal yalnızca localStorage kullanınca telefondan gelen cevaplar görünmez.
Bu kilit sunucu tarafı WaChatMessage + Green API webhook + 4 sn polling akışını korur.

── Beklenen davranış ───────────────────────────────────────────────────────
  • Üye oturumu + Hesabım’da kayıtlı cep telefonu zorunlu (equsto-wa-phone-gate)
  • Modal açıkken GET /api/whatsapp/chat ile 4 sn polling (since= artımlı)
  • Müşteri modalden yazınca: POST /api/musteriler (kaynak: whatsapp-modal) → DB user satırı
  • Sahip bildirimi: notifyWhatsAppModalLead → WHATSAPP_NOTIFY_TO (532, Green API ile aynı hat)
  • Otomatik «mesajınız alındı» cevabı: notifyCustomerLeadAck → team satırı (waMessageId)
  • Telefondan müşteriye yazılan: Green API outgoingMessageReceived → webhook → team satırı
  • Müşteriden gelen WA: incomingMessageReceived → webhook → user satırı
  • İç numaralar (vitrin / notify) isInternalWhatsAppPhone ile filtrelenir
  • Green API GET /api/whatsapp/webhook → 200 JSON (panel URL kontrolü; Forbidden değil)

── Green API webhook (Hetzner / configure script) ───────────────────────────
  URL: https://equsto.com/api/whatsapp/webhook
  • incomingWebhook = yes          (Gelen mesaj…)
  • outgoingMessageWebhook = yes   (Telefondan gönderilen…)
  • outgoingAPIMessageWebhook = yes (API'den gönderilen…)
  Script: node --import ./scripts/load-env.mjs scripts/configure-green-api-webhook.mjs
