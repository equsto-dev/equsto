Bu kilitleme oturum boyunca onaylanan PFOS halk akışı, üye zorunluluğu,
teklif PDF teslimi, WhatsApp modal üye kapısı, giriş sayfası vitrin bandı,
kayıt (telefon + şifre tekrar) ve Amazon tarzı /hesabim merkezini korur.

── 1. PFOS halk sihirbazı ─────────────────────────────────────────────────
  • Üye girişi sihirbaz BAŞINDA (son adımda değil) — giriş sonrası akış sıfırlanmaz
  • Giriş/kayıt linkleri ?next= ile PFOS'a geri döner (pfosLoginHref / pfosRegisterHref)
  • «Üye Girişi» + «Kayıt ol» kapısı (memberGate)
  • Panel geçişleri sakin: PFOS_PANEL_FADE_MS=580, secPending/secReveal (clip-path YOK)
  • Proforma: deliveryOnly — yalnızca e-posta / WhatsApp PDF; indirme yok
  • Girişli üye bilgi formu görmez; profil equsto_member_v1 / checkout'tan gelir

── 2. Teklif API ve teslim ─────────────────────────────────────────────────
  • POST /api/teklifler ve /api/musteriler → requireMemberSession zorunlu
  • PDF: Resend e-posta + Green API WhatsApp (EQUSTO_WHATSAPP_MODE=green-api)
  • İndirme butonu halk PFOS'ta kapalı (deliveryOnly)

── 3. WhatsApp modal (Mr. Equsto) ──────────────────────────────────────────
  • Sohbet öncesi üye kapısı — PFOS ile aynı «Üye Girişi» + «Kayıt ol»
  • WA_MODAL_BUILD = 25 (DOM yenileme kilidi)
  • equstoLoginHref / equstoRegisterHref ile ?next= geri dönüş
  • Telefon kapısı: equsto-wa-phone-gate → /hesabim#guvenlik (mesaj öncesi zorunlu)
  • Stil: .equsto-wa-login-gate__btn (lacivert), __register linki

── 4. Giriş / kayıt sayfası ──────────────────────────────────────────────
  • AuthVitrinChrome: vitrin üst bant + kategori çekmecesi (header/topnav)
  • auth.css: köşe auth-topbar gizli (--eq-shop-chrome-h padding)
  • E-posta kayıt: cep telefonu ZORUNLU (auth-phone, ShopMember.telefon)
  • Kayıt: şifre tekrar alanı (auth-password2) — eşleşme kontrolü
  • redirectAfterAuth: ?next= (Google/Apple dahil)

── 5. Hesabım merkezi ────────────────────────────────────────────────────
  • /hesabim — Amazon tarzı kart + link sütunları (MemberAccountHub)
  • Üst başlıkta çıkış yok; «Giriş ve güvenlik» adres kartı stili — Adres Defterim solunda; alt sağda Çıkış yap
  • Telefon yoksa sarı banner + otomatik düzenleme; Google giriş sonrası #guvenlik
  • eq-site-urls.js: account → /hesabim (EN: /en/account)
  • equsto-member.js: girişli header → equstoUrl("account"); equstoMemberHasPhone()
  • next.config: hesabim.html → /hesabim yönlendirmesi
  • SHOP_ASSET_V = 20260621-drawer-ice-blue
