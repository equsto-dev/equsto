# proje-veri — kaynak dosyalar

Sizin eklediğiniz ve buraya taşıdığınız **kaynak** dosyalar.

| Tür | Örnek |
|-----|--------|
| Ekipman listesi PDF | `03-italyan.pdf`, `06 SUSHI.pdf` |
| Plan PDF | `ITALYAN-PLAN.pdf`, `SUSHI.-PLANpdf.pdf` |
| Ekipman Excel | `03-italyan-ekipman-listesi.xlsx`, `06-SUSHI-ekipman-listesi.xlsx` |
| Alt klasörler | `BALIKCI/`, `STEAKHOUSE/`, `FAST FOOD/` |

**Üretilmiş çıktılar** (birleşik, ölçek matrisi, JSON, script’ten yeni Excel) → bir üst dizin: `../` (`veri/`).

Scriptler: okuma `proje-veri/` · yazma (işlenmiş) `veri/`.
